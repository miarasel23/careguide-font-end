Secure Note-Taking REST API Documentation

Modular Domain Architecture powered by Node.js, Express.js, and Mongoose. Features Role-Based Access Control (RBAC), MongoDB Aggregation Pipelines (Scenario 1 & 2), and ESR-Optimized Indexing (7 explicit schema.index() definitions with zero redundant indexes).

Open Live Web Dashboard → Backend GitHub Repository Active Live API Endpoint

1. Authentication Endpoints

POST /api/v1/auth/login Authenticate with email & password to receive JWT token
POST /api/v1/auth/register Register new user account (role: user)
GET /api/v1/auth/me Fetch currently authenticated user profile

Default Demo Accounts: Admin (admin@example.com / Admin@123), User (user@example.com / User@123)

2. Notes Management (RBAC & Pagination)

GET /api/v1/notes?page=1&limit=10 List user's own notes (Admin views all notes)
POST /api/v1/notes Create note { title, content }
PUT /api/v1/notes/:id Update existing note
DELETE /api/v1/notes/:id Delete personal note (Admin can delete any note)

3. Admin User Management (Role Protected)

GET /api/v1/admin/users?page=1&limit=10 List all registered users (Admin only)
POST /api/v1/admin/users Create user with role and interests array
PUT /api/v1/admin/users/:id Update user credentials, role or interests
DELETE /api/v1/admin/users/:id Delete user account

4. MongoDB Aggregation Pipelines (Technical Interview Requirement)

GET /api/v1/aggregations/group-by-interests Scenario 1: Group users by interests via single collection.aggregate()
GET /api/v1/aggregations/user-posts?userId=:id Scenario 2: Retrieve user and join posts via single $lookup stage
GET /api/v1/aggregations/indexes Inspect live MongoDB collection indexes (7 custom ESR indexes)
